Where the work lives now

A snapshot of current-state multi-tool selection, as of mid-2026. Each tool is used for what it does well. The selection is empirical, not abstract.

GPT

Gemini
Critique
  • Second opinion on TEDx applications
  • Critique of monitoring / evaluation kits
  • Essay-draft critique
A third reader. Narrow scope: specifically used to stress-test work that has already been drafted elsewhere. Light usage so far, deliberate.

How work moves between them

Raw thinking → Claude (draft) → GPT (voice + visuals) → Gemini (critique) → Polished artifact (my voice)
Not a strict pipeline — most work uses one tool. When work crosses tools, this is the most common pattern: deep draft on Claude, voice or visual polish on GPT, critique pass on Gemini. The artifact that ships is mine, integrated from whatever each tool contributed.

The selection principle

Each tool is matched to its actual strength, observed over time. The working pattern — pre-work practice, voice protection, sycophancy detection, iteration tolerance — is the same across all three. That’s mine. The tools differ in what they enable. Maturity does not transfer because of which tool I use. It transfers because the discipline lives in me, not in the tool.
